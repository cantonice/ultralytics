# SF模块消融实验论文级分析报告

## 1. 数据与方法
- 数据来源：results目录下四组500轮对比实验（baseline/v1/v2/v2plus）。
- 评价口径：以每组`mAP50-95`最高轮次作为主比较点，同时给出最终轮次与后50轮稳定性统计。
- 说明：当前为单次训练结果，尚不构成统计显著性结论，建议补充多seed重复实验。

## 2. 核心结论
- 最优综合精度来自 **v2plus**，其 best mAP50-95 = 0.8417。
- v1 相对 baseline 的变化：ΔP=+4.42 pp, ΔR=+2.13 pp, ΔmAP50=+0.89 pp, ΔmAP50-95=-0.28 pp。
- v2 相对 baseline 的变化：ΔP=+3.94 pp, ΔR=-0.23 pp, ΔmAP50=+1.64 pp, ΔmAP50-95=+0.32 pp。
- v2plus 相对 baseline 的变化：ΔP=+1.76 pp, ΔR=-0.77 pp, ΔmAP50=+0.09 pp, ΔmAP50-95=+0.62 pp。

## 3. 学术写作建议（硕士论文）
- 建议同时报告全量结果与场景子集结果，避免只呈现优势样本导致结论偏置。
- 对不利指标应给出边界解释（例如precision下降与门控策略敏感性相关）。
- 最终论文建议补充3~5个随机种子并报告均值±标准差。

## 4. 产出文件
- summary_selected.csv：每个变体保留一条代表性结果（按best mAP50-95选取）。
- summary_all_runs.csv：所有run汇总。
- delta_vs_baseline.csv：相对baseline增益。
- fig1~fig4：性能对比、增益、收敛、效率权衡图。
