# 实验结果与分析（论文草稿）

## 1. 实验环境与共有设置

### 1.1 实验软硬件平台
为确保实验结果的客观性与可复现性，本章消融实验与对比实验均在同一套标准化计算环境中独立运行，未启用分布式多卡以避免受 Batch Normalization 异步通信的干扰。具体的软、硬件环境配置如下表所示：

| 环境参数 | 配置详情 |
| :--- | :--- |
| **操作系统** | Ubuntu 20.04.5 LTS |
| **CPU** | Intel / AMD 处理器核心（多线程支持） |
| **GPU** | NVIDIA GeForce RTX 4090 D (24GB 显存) |
| **CUDA版本** | 12.8 |
| **深度学习框架** | PyTorch 2.10.0 |
| **Python环境** | Python 3.10 |

### 1.2 统一训练超参数设置
在所有模型的训练过程中，除网络结构的改变外（即改变 Backbone 相关模块结构），数据输入管线与基础训练超参数维持完全一致，如下：
- **输入分辨率（imgsz）**：图像统一缩放为 `640 x 640`。
- **批量大小（Batch Size）**：设定为 `16`，由 8 个工作进程（Workers）进行异步数据加载。
- **网络训练步长（Epochs）**：四组消融模型均设为 `500` 轮，以确保充分捕捉频域模型的收敛长尾效应。
- **随机种子（Seed）**：所有实现均设定 `seed = 0`，并开启了决定性操作（`deterministic = true`）以确保每次反向传播计算路径一致，大幅降低抖动方差。
- **优化器与精度**：启用自动混合精度训练（AMP, `amp=true`）以加速收敛并在 24GB 显存下平滑处理所有多分支张量；其余学习率与损失函数权重沿用 YOLO 框架对默认玻璃缺陷任务的最优推荐值。

## 2. 实验目的与对比模型定义
本节围绕 SF 模块的有效性开展消融实验，对比四种模型：baseline、v1、v2、v2plus。为保证结论可复现，本次对比使用同一数据集、同一训练配置与统一评估口径，采用 mAP50-95 作为主要指标，并同时报告 precision、recall 与 mAP50。

## 2. 结果统计口径
- 主比较点：每个模型在训练过程中 mAP50-95 的最佳轮次（best epoch）。
- 补充指标：最终轮次性能、训练总时长、后 50 轮 mAP50-95 波动（稳定性指标）。
- 注意事项：当前每组仅单次训练，结论反映趋势，不构成统计显著性结论。

## 3. 定量结果（最佳轮次）

| 模型 | Best Epoch | Precision | Recall | mAP50 | mAP50-95 | 训练时长(h) |
|---|---:|---:|---:|---:|---:|---:|
| baseline | 494 | 0.8799 | 0.9152 | 0.9500 | 0.8356 | 1.548 |
| v1 | 313 | 0.9240 | 0.9365 | 0.9589 | 0.8328 | 1.743 |
| v2 | 265 | 0.9192 | 0.9129 | 0.9664 | 0.8388 | 1.496 |
| v2plus | 500 | 0.8975 | 0.9075 | 0.9509 | 0.8418 | 1.992 |

## 4. 相对 baseline 的增益（百分点，pp）

| 模型 | ΔPrecision | ΔRecall | ΔmAP50 | ΔmAP50-95 | Δ训练时长(h) |
|---|---:|---:|---:|---:|---:|
| v1 | +4.42 | +2.13 | +0.89 | -0.28 | +0.195 |
| v2 | +3.94 | -0.23 | +1.64 | +0.32 | -0.052 |
| v2plus | +1.76 | -0.77 | +0.09 | +0.62 | +0.444 |

## 5. 结果分析（硕士论文写法）
1. 从主指标 mAP50-95 看，v2plus 达到最高值 0.8418，较 baseline 提升 +0.62 pp，说明增强后的频域分支与融合策略在综合定位与分类质量上具备增益。
2. v2 在 mAP50 上提升最明显（+1.64 pp），同时 mAP50-95 也有 +0.32 pp 提升，并且训练时长略低于 baseline，表现出较好的精度-效率平衡。
3. v1 虽在 precision 与 recall 上提升明显，但 mAP50-95 下降 -0.28 pp，表明其增益主要集中在较宽松阈值下，严格 IoU 评价下的泛化能力仍有不足。
4. 就训练稳定性（后 50 轮波动）而言，v2plus 的 mAP50-95 标准差最低，说明其收敛末段更平稳，但训练代价更高。

## 6. 边界与局限
- 当前结果来自单次训练，可能受随机种子影响。建议补充 3~5 个随机种子，并报告均值±标准差。
- 对“优势场景”与“不利场景”应同时报告，不应仅展示有利样本，以保证结论可信。
- 若论文需强调工程可用性，可增加“单位训练时长收益”分析（例如每小时 mAP50-95 增益）。

## 8. 可直接复用的结论句
综合比较可见，v2plus 在主指标 mAP50-95 上取得最优结果，验证了所提频域增强策略在严格评价口径下的有效性；v2 则在精度与效率之间提供了更均衡的方案。整体上，SF 模块改进路径具备实际效果，但不同变体在 precision、recall 与训练成本上的权衡差异明显，后续仍需通过多随机种子与场景子集分析进一步强化统计稳健性。
